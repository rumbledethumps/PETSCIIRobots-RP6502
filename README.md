# PETSCIIRobots-X16
Attack of the Petscii Robots - Commander X16 
The Attack of the PETSCII Robots source code has been provided by David Murray for the 

purposes of study and also to provide information to those who would like to port the game 

to other systems. This code may NOT be used to produce unofficial copies for sale and the 

code must NOT be modified in anyway unless adding a feature, in which both the source and 

compiled versions must be sent to David Murray. 

Due to time constraints, David Murray will NOT be prodiving support. He has gladly given 

permission for me to host this.

The Commodore 64 REU and Commodore 128 versions were coded by Scott Robison, who sadly 

passsed away in August 2022, so please do not attempt to contact his family to ask 

questions about it. His widow found the folder containing the source code to these 

versions but we have no way of knowing if these are the latest builds. 

## Controls (RP6502 port)

A gamepad is always live, whichever keyboard scheme is selected — plug one in
and it works. The intro menu's control option chooses only which *keys* are
used: **default**, or **custom**, which asks you for thirteen of your own when
you start the game. The menu itself can be driven with either.

### Gamepad

| Input | Action |
| --- | --- |
| D-pad, or left stick | Walk |
| Face buttons, or right stick | Fire in that direction |
| L1 | Search |
| R1 | Push / move object |
| Start | Use item |
| Select + L1 | Cycle item |
| Select + R1 | Cycle weapon |
| Select + Left | Live map |
| D-pad / Start / bottom button | Navigate and choose, in menus |

Face buttons fire in the direction of the button under your thumb — top fires
up, bottom fires down, left fires left, right fires right — regardless of
whether the pad labels them in the Nintendo, Xbox or PlayStation arrangement.

### Keyboard (default)

| Key | Action |
| --- | --- |
| I K J L | Walk up, down, left, right |
| W S A D | Fire up, down, left, right |
| F1 / F3 | Cycle weapon / item |
| Space | Use item |
| Z | Search |
| M | Push / move object |
| Tab | Live map |
| Esc | Pause, and offer to quit |

Cursor keys also walk, and choose in menus.
