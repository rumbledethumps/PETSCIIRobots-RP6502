# Video bring-up: the three planes come up, the game screen loads into the
# bitmap plane, and level-a's map window is drawn into the character plane.
#
# Determinism comes from the harness (--mute --seed 1 --tmpdrive). Selecting a
# canvas takes the console away and it stays away, so a frame hash is stable.
#
# The peeks are the durable assertions: they check the character cells the tile
# plotter wrote against tools/convert/conv_tiles.py's output, so a bug in the
# tileset reorganisation, the cell address arithmetic or the portal writes shows
# up here and names itself. The CRC catches everything else at once but churns
# on any art change, so it is one line, not eleven.

# Start the game from the intro menu. START GAME is the first option, so space
# is enough; the tests that care about the menu itself drive it further.
wait "MENU"
run 30
press space
run 6
release space

wait "BRINGUP OK"

# Cells are {glyph, colour} pairs. The colour byte's high nibble is 0 because
# conv_tiles.py pre-masks it, which is what keeps the playfield transparent over
# the bitmap plane underneath.
# tile 132 at window (3,1)
peek xram:$97A2 $D1 $01 $5F $0F $DF $0F
# tile 133 at window (4,1)
peek xram:$97A8 $20 $01 $2E $05 $20 $01
# tile 136 at window (3,2)
peek xram:$9892 $20 $01 $8F $0F $7F $0F
# tile 137 at window (4,2)
peek xram:$9898 $CE $0C $DF $0C $3B $05
# tile 206 at window (7,0)
peek xram:$96CA $E8 $09 $68 $09 $E8 $08
# tile 207 at window (7,1)
peek xram:$97BA $E6 $09 $3B $05 $68 $08
# tile 208 at window (0,0)
peek xram:$96A0 $5E $05 $20 $01 $3B $05
# tile 209 at window (1,3)
peek xram:$9976 $20 $01 $3A $05 $20 $01
# tile 210 at window (9,0)
peek xram:$96D6 $5E $05 $20 $01 $3B $05
# tile 223 at window (10,0)
peek xram:$96DC $00 $05 $55 $05 $00 $05
# tile 225 at window (0,6)
peek xram:$9C40 $6C $01 $3B $05 $20 $01

# The font must have been transposed to row-major: mode 1 reads
# font[row * 256 + glyph], so glyph 1 ('A') row 0 lives at XR_FONT + 1.
peek xram:$A001 $7E

# The palettes load straight into XRAM from the ROM: bitmap entry 0 opaque
# black, character entry 0 transparent, player entry 4 opaque black.
peek xram:$E000 $20 $00
peek xram:$E020 $00 $00
peek xram:$E048 $20 $00

# The probe block is the durable state assertion: a fixed XRAM address, so it
# does not move when the linker rearranges RAM. 'P','R', playing, level a,
# player at 22,38, and the window centred on him at 17,35.
peek xram:$FE00 $50 $52 $02 $00 $16 $26
peek xram:$FE0A $11 $23

# Anchor the frame on the AI's own clock rather than on `run 60`. How long
# booting takes depends on the host filesystem, so counting frames from the
# console line is not the same measurement on every machine.
wait "AI60"

# One golden frame. Regenerate with: python3 tools/emu-crc.py tests/emu/bringup.txt
expect-crc 88D7C857
shot "bringup.png"
