# Dying, and the screens that follow.
#
# plat_game_over has two branches and only the win one had ever been tested. On
# a death it faces the sprite FACE_DEAD, holds while the world keeps running,
# then shows the box, the endgame statistics and LOS_MSG. tests/emu/endgame.txt
# covers the win.
#
# Three faults were reported here and all three came from one line: this port
# called BACKGROUND_TASKS inside the waits. The original runs it in GOM0 only --
# while the body is on screen and whatever killed him is still moving, which is
# the point -- and nowhere after the box goes up. Running it later left a robot
# attacking the corpse behind the GAME OVER box and, because BACKGROUND_TASKS
# redraws the map window whenever REDRAW_WINDOW is set, drew the playfield back
# over the statistics.
#
# The player is killed by writing his unit type, which is what the AI does at
# the end of INFLICT_DAMAGE. Taking real damage is covered by
# tests/emu/flash.txt, which is driven by a hazard hitting the player; what
# needs testing here is what happens afterwards, and a route that walks into a
# robot cannot test it -- the probe is not refreshed while plat_game_over runs,
# so a recorded route keeps walking and its keypresses dismiss the very screens
# under test. See the note in tools/playthrough.py.
#
# @SYMBOL@ is a RAM address resolved from the linker map when the tests are
# generated. XRAM addresses stay literal -- the program picks those.

wait "MENU"
run 30
press space
run 6
release space
wait "BRINGUP OK"
run 60

poke @UNIT_TYPE@ $00
run 60

# GOM0: the body is on screen and the world is still moving, so this is still
# the playfield rather than the box.
peek xram:$FE02 $03

# GOM2: the box. Three rows at column 11 of rows 9 to 11; row 10 is the words.
run 120
peek xram:$9936 $5D $01 $07 $01 $01 $01 $0D $01 $05 $01 $20 $01 $0F $01 $16 $01 $05 $01 $12 $01 $5D $01

# And it stays. Five seconds with nothing pressed: the wait has to be a wait,
# not something the next thing to happen scrolls past.
run 300
peek xram:$9936 $5D $01 $07 $01 $01 $01 $0D $01 $05 $01 $20 $01 $0F $01 $16 $01 $05 $01 $12 $01 $5D $01

# One key, and the statistics. "you lose!" at row 3 from column 16.
press space
run 8
release space
run 120
peek xram:$9710 $19
peek xram:$9712 $0F
peek xram:$9714 $15
peek xram:$9716 $20
peek xram:$9718 $0C
peek xram:$971A $0F
peek xram:$971C $13
peek xram:$971E $05
peek xram:$9720 $21

# Which also stays, rather than flashing past on the same keypress that got
# here -- GOM5 drains what is waiting before it waits for something new.
run 300
peek xram:$9710 $19
peek xram:$9712 $0F
peek xram:$9714 $15
peek xram:$9716 $20
peek xram:$9718 $0C
peek xram:$971A $0F
peek xram:$971C $13
peek xram:$971E $05
peek xram:$9720 $21

# And the last key returns to the intro.
press space
run 8
release space
wait "MENU" 400
