# The elevator panel.
#
# Written during M6 and never tested, because no level puts an elevator anywhere
# a script can walk to: every one of the thirty in the fourteen levels is behind
# a locked door, and the shafts themselves are not walkable terrain. poke gets
# past that by putting the player where the game would have put him.
#
# ELEVATOR_PANEL triggers on the player standing at the elevator's X and one row
# ABOVE it -- x16Robots.ASM ELPN1 does UNIT_LOC_Y[elevator] - 1 and compares.
# level-e's elevator slot 41 is at 52,24 with four floors and the car on floor
# 1, so the player goes to 52,23.
#
# RAM addresses come from build/.../robots.map: UNIT_LOC_X $7840, UNIT_LOC_Y
# $7880. The panel is drawn at character row 29 from column 7, which is
# XR_CHARS + 29*80 + 7*2 = $9F1E, two bytes per cell.

wait "MENU"
run 30
press k
run 6
release k
run 10
press space
run 6
release space
run 10
press space
run 6
release space
run 10
press space
run 6
release space
run 10
press space
run 6
release space
run 10
press i
run 6
release i
run 10
press space
run 6
release space
wait "BRINGUP OK"
run 20

# Stand him at 52,23. The nudge down and back up is what makes the game redraw
# the window around him and lets the elevator's AI see him arrive.
poke $7840 $34
poke $7880 $17
press k
run 8
release k
run 8
press i
run 8
release i
run 90

# Four floors offered, the car's own floor inverted: colour $50 against $05.
peek xram:$9F1E $31 $50 $32 $05 $33 $05 $34 $05

# Right twice, and the highlight walks up with it.
press l
run 8
release l
run 20
peek xram:$9F1E $31 $05 $32 $50 $33 $05 $34 $05
press l
run 8
release l
run 20
peek xram:$9F1E $31 $05 $32 $05 $33 $50 $34 $05

# Left comes back down. It stops at 1 and at the top, which is why the panel
# never offers a floor the shaft does not have.
press j
run 8
release j
run 20
peek xram:$9F1E $31 $05 $32 $50 $33 $05 $34 $05

# Down leaves: the digits are cleared and the player is put out at the chosen
# floor -- slot 38 is that shaft's floor 2 at 7,12, and he arrives one above it
# at 7,11, which is where the panel expects a player to be standing.
press k
run 8
release k
run 40
peek xram:$9F1E $20 $05 $20 $05 $20 $05 $20 $05
peek xram:$FE04 $07 $0B
