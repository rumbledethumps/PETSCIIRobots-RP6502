# On the hazard, untouched.
peek xram:$FE04 $4B $2A
peek xram:$FE06 $0C

# It hurts him repeatedly, which is what sets BORDER: INFLICT_DAMAGE writes 10
# there whenever the unit it hurts is the player. Health settles at 1 and the
# hazard loses interest, so this is a plateau rather than a moment.
run 200
peek xram:$FE06 $01

# The ramp itself is checked by driving it rather than by catching it, because
# the emulator does not deliver an exact number of frames per `run` -- the same
# script gives 143 or 144 VSYNC ticks -- and a ten-frame ramp read at a fixed
# offset lands on a different step each time. Writing the countdown instead
# makes the check independent of when the last hit landed.
#
# Index 6 of the ramp is 31, and so is index 5, so this reads the same whether
# one tick or two have gone by. Red occupies the low five bits of the RGB555
# entry and bit 5 is the opacity flag: $3F is full red, opaque.
poke $60CF $06
run 1
peek xram:$E000 $3F $00
run 1
peek xram:$E000 $3F $00

# The countdown reaching zero is what says the interrupt walked it, and entry 0
# going back to opaque black is what says it cleaned up. Leaving it tinted would
# stain the whole playfield for the rest of the game.
run 40
peek $60CF $00
peek xram:$E000 $20 $00
