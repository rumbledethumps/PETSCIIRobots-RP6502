# On the hazard, untouched.
peek xram:$FE04 $4B $2A
peek xram:$FE06 $0C

# One hit: health down one, and entry 0 part way up the red ramp. The ramp is
# 8, 15, 25, 31 and back, in the five bits RGB555 gives red -- the X16 saw 8,
# 15, 9, 15 because VERA reads only four of them.
run 12
peek xram:$FE06 $0B
peek xram:$E000 $39 $00

# Still being hit, and at the top of the ramp.
run 36
peek xram:$FE06 $07
peek xram:$E000 $3F $00

# The hazard stops and entry 0 goes back to opaque black -- the opacity bit set,
# every colour component zero. Leaving it tinted would darken or stain the whole
# playfield for the rest of the game.
run 24
peek xram:$FE06 $06
peek xram:$E000 $20 $00
